# Incoming data

Drop new information here first: manual pages (PDF or photos), pasted text, notes from the field.

Nothing in this folder is in the app. Each piece gets checked first:
1. Compare it with what the guide already has.
2. Mark it NEW, DUPLICATE or CONFLICT, with the source (document, revision, page).
3. Add only what you approve, word for word as printed. No guessing, no filling gaps.
4. The nameplate and the unit's own manual win over anything here.

Keep R-410A and R-32 data separate.
